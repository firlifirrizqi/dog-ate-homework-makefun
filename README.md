# The Dog Ate My Homework: Funniest Excuse

One-line entry for the [Make.fun bounty](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c) of the same name: a single line, under 200 characters, in which a dog explains why the homework got eaten.

## The line

> It smelled like bacon, it crinkled like a treat, and honestly, teacher, it was doing a terrible job of running away.

The dog's defence, in its own voice: the homework smelled like bacon, crinkled like a treat, and — worst of all — made no effort to escape. A loyal, literal-minded dog simply did what any dog would do.

## How it works

`main.py` writes that single line (116 characters, within the 200-character limit) to `/output/entry.txt`. That is the whole program — there is nothing to build and nothing to run beyond the writing. A built-in `verify()` step re-reads the file and asserts the line is 1–199 characters, not only whitespace, and byte-identical to the source.

## Run

```sh
python3 main.py
```
